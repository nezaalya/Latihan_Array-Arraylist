# Latihan Array & ArrayList - Pemrograman Berorientasi Objek

Repository ini berisi tugas mata kuliah Pemrograman Berorientasi Objek mengenai implementasi Array dan ArrayList, serta penerapan konsep **Encapsulation** pada program Bank Account.

## Penjelasan Konsep
- **Encapsulation**: Digunakan pada class `Bank` dengan menyembunyikan data utama (`private double balance` dan `private ArrayList<String> transactionHistory`) serta mengelolanya melalui method publik seperti `deposit()`, `withdraw()`, dan `getBalance()`.
- **ArrayList**: Digunakan untuk menyimpan dan mengelola riwayat transaksi (`transactionHistory`) secara dinamis di dalam class `Bank`.
